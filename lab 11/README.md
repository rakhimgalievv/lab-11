# Лабораторная работа № 11 — React Props и State

## Тема
Введение в фреймворки: React. Создание компонентов, передача `props` и управление локальным состоянием `state`.

## Проект
**ExpenseFlow** — веб-приложение для учёта личных расходов. Реализованы три уровня сложности: лёгкий, средний и высокий.

## Запуск без установки зависимостей проекта
1. Распакуйте архив в любую папку.
2. Дважды нажмите `start.bat`.
3. Скрипт запустит встроенный сервер Windows PowerShell и откроет `http://127.0.0.1:8000`.
4. Сервер работает в отдельном окне **Lab 11 Server**. Чтобы остановить его, закройте это окно.

Python, Node.js, npm и установка библиотек не требуются. Приложение использует React 18 и Babel с CDN, поэтому для загрузки React при первом открытии требуется подключение к интернету. Данные расходов сохраняются в `localStorage` браузера.

## Цель работы
Научиться создавать компонентный пользовательский интерфейс на React, передавать данные от родительского компонента дочернему через `props`, хранить и изменять локальное состояние с помощью `useState`, реагировать на действия пользователя и проверять корректность приложения.

## Теоретические сведения
- **Компонент** — независимая часть интерфейса с собственным представлением и поведением.
- **Props** — входные данные, передаваемые компоненту родителем. Дочерний компонент не изменяет полученные `props`.
- **State** — данные компонента, изменение которых вызывает обновление интерфейса.
- **useState** — React Hook для хранения локального состояния.
- **Обработчик onClick** — функция, которая запускается при нажатии на кнопку.
- **Повторный рендер** — обновление представления компонента после изменения состояния.

## Индивидуальное задание
Вариант на основе повышенного уровня, № 16: «Планировщик расходов». Компоненты `ExpenseForm` и `ExpenseList`; родитель хранит список расходов, общую сумму и фильтр категорий.

### Уровни сложности
1. **Лёгкий:** добавление и удаление расходов, подсчёт общей суммы и количества записей.
2. **Средний:** поиск по названию, фильтрация по категориям и сортировка по сумме или дате.
3. **Высокий:** все функции среднего уровня, редактирование суммы, настройка бюджета, индикатор расходования бюджета и сохранение данных в `localStorage`.

## Компонентная структура и поток данных
- `App` — родительский компонент. Хранит массив расходов, уровень сложности, фильтры и бюджет.
- `Header` — получает `level` и `onLevelChange` через `props`.
- `ExpenseForm` — получает `onAdd` и `advanced` через `props`; собственное состояние полей формы хранит через `useState`.
- `ExpenseList` — получает массив `expenses`, функции `onDelete`, `onEdit` и флаг `editable` через `props`.
- `ExpenseItem` — получает отдельный объект расхода и обработчики через `props`.
- `StatCard` — получает подпись, значение, пояснение и иконку через `props`.
- `FilterBar` — получает значения фильтров и функции их изменения через `props`.

Поток данных: родитель `App` передаёт данные и функции дочерним компонентам через `props`. Дочерние компоненты вызывают переданные обработчики, а родитель изменяет `state` через функции-сеттеры `useState`. Props напрямую не изменяются.

## Контрольные вопросы и ответы
1. **Что такое компонент?** Независимая часть интерфейса с собственным представлением и поведением.
2. **Для чего нужны props?** Для передачи данных от родительского компонента дочернему.
3. **Почему props считаются входными данными?** Их получает компонент извне и не должен изменять самостоятельно.
4. **Что такое state?** Внутренние данные компонента, изменение которых обновляет интерфейс.
5. **Как работает useState?** Возвращает текущее значение состояния и функцию для его изменения.
6. **Когда происходит повторный рендер?** В частности, после изменения состояния компонента.
7. **Как обработать click в React?** Передать функцию в JSX-атрибут `onClick`.
8. **Почему нельзя изменять state прямым присваиванием?** React должен получить обновление через setter, чтобы корректно запланировать рендер.
9. **Чем локальное состояние отличается от props?** State принадлежит компоненту; props передаются ему родителем.
10. **Как передать обработчик из родителя ребенку?** Передать функцию как prop.
11. **Что такое управляемое поле ввода?** Поле, значение которого задаётся состоянием React, а изменение обрабатывается через `onChange`.
12. **Как проверить независимость двух экземпляров компонента?** Создать два экземпляра и убедиться, что изменение состояния одного не меняет другой.
